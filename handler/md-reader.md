# install complete

Two steps are left:

1. Press ⇧⌘\\ or click expand at the top of this pane. It stays expanded for later files.
2. In Finder, choose Get Info on a `.md` file, set Open With to `md-reader`, and click Change All.

Then double-click any Markdown file in your home folder, and it opens here.

Don't chat in this session, because it can reach your whole home folder.
